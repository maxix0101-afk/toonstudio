# 🎨 ToonStudio

Einfache Browser-App zum Erstellen von Zeichentrickfilmen – **komplett offline nutzbar**, ohne Installation und ohne Internet.

## So geht's
1. `index.html` herunterladen (grüner **Code**-Knopf → **Download ZIP**, oder Datei direkt öffnen)
2. Die Datei per Doppelklick im Browser öffnen
3. Loszeichnen! 🖊

## Funktionen
- Verschiedene Stiftarten: Stift, Bleistift, Pinsel, Marker, Radierer, Füllwerkzeug
- Onion Skin: vorherige Folien als Geisterlinie überlagert
- Timeline mit Miniaturvorschau, Folien hinzufügen/duplizieren/löschen
- Abspielen mit 1–24 FPS
- Export als WebM-Video oder PNG-Folien
- Projekt als JSON speichern/laden
- Tastenkürzel: `B` Stift · `P` Bleistift · `S` Pinsel · `M` Marker · `E` Radierer · `F` Füllen · `Strg+Z/Y` · `←/→` · `N` · `Leertaste`
